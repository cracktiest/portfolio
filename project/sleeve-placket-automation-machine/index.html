Overview

This project transformed an existing programmable Jooke AMS sewing machine into a dedicated sleeve placket automation solution. The result was a cost-effective alternative to expensive commercial machines, while maintaining production quality and improving operational efficiency.

How the machine works

The working principle of this machine is shown in the video below. It demonstrates how the system automates sleeve placket processing by combining mechanical motion, sensing, and synchronized sewing operation to reduce manual handling.

Challenge

  • Commercial sleeve placket machines cost around IDR 400 million, making large-scale deployment difficult.
  • The objective was to develop a cost-effective solution using existing equipment.
  • The automation system needed to maintain product quality while improving speed and consistency.

Solution

System Integration

Collaborated with the Production Development team to integrate pneumatic cylinders, servo mechanisms, sensors, and an Arduino-based control system with a Jooke AMS sewing machine.

State-Based Control

A state-based controller managed material positioning, automatic clamping, sewing synchronization, and material release.

Automation Workflow

The standard sewing machine was repurposed to perform sleeve placket operations automatically with minimal manual handling.

Result

  • Successfully transformed a standard Jooke AMS machine into a dedicated sleeve placket automation machine.
  • Reduced development costs to less than IDR 100 million, about 75% lower than commercial alternatives.
  • Improved production efficiency by minimizing manual handling during sewing.
  • Demonstrated that existing equipment could be repurposed into specialized automation machines.
  • Inspired additional automation solutions for garment production.
  • Contributed to receiving the Best Employee 2024 award for innovation and manufacturing automation.

Conclusion

This project became a major milestone in my engineering career by demonstrating how practical innovation could generate significant business value. It strengthened collaboration between the Robotics and Production Development teams and became the catalyst for multiple automation initiatives across the factory.
