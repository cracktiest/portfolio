Overview

Developed a digital sewing pattern projection system for the Sample Pattern Department at PT Gistex Garmen Indonesia (Cileunyi). The project replaced conventional printed paper patterns by projecting cutting outlines directly onto fabric using a high-resolution projector, enabling faster pattern preparation and more flexible sample development.

Challenge

  • The traditional sample pattern process relied on printed paper templates that required continuous printing, manual placement, and physical storage.
  • This resulted in longer preparation times, increased material consumption, and limited flexibility for pattern revisions.

Solution

Projection System Design

Designed and implemented a digital projection system that accurately displayed garment cutting patterns directly onto fabric surfaces.

Calibration & Alignment

Calibrated the projector to maintain projection accuracy and scale, ensuring the pattern matched fabric dimensions and cutting layout.

Workflow Integration

Optimized the workstation for quick fabric positioning and pattern alignment, integrating the solution into the existing sample development process.

Result

  • Successfully deployed the sewing pattern projection system within the Sample Pattern Department at PT Gistex Garmen Indonesia – Cileunyi.
  • Significantly reduced paper template usage, accelerated sample preparation, and simplified design revisions.
  • Improved workflow efficiency while maintaining cutting accuracy.
