Overview

After gaining access to the robot SDK and API, I led the second-stage development of the factory’s AMR ecosystem. The project focused on building a custom fleet management dashboard that enabled real-time robot monitoring, operational analytics, and system integration with existing factory workflows.

Challenge

  • The standard robot management software provided limited flexibility for factory-specific workflows.
  • Production teams needed a centralized platform for robot locations, task status, charging activity, operational history, and fleet performance.
  • Integration with internal manufacturing systems was necessary to support real operational use.

Solution

Fleet Management Architecture

Designed the architecture for a web-based fleet management platform that could communicate directly with the robot fleet using SDK and REST API integration.

Real-Time Dashboard

Developed a dashboard for live robot locations, operational status, task history, charging status, idle time, and mission tracking.

Factory Workflow Integration

Enabled dispatch of robots from external applications and connected the platform with manufacturing workflows.

Telegram Dispatch Support

Supported chat-based robot dispatch through Telegram using n8n integration developed by a team member.

Result

  • Developed a custom real-time robot fleet management dashboard.
  • Integrated directly with robot SDK and REST APIs.
  • Displayed live robot locations on factory maps.
  • Monitored task duration, charging duration, and idle duration.
  • Recorded movement history and operational logs.
  • Established the software foundation for future robot automation and third-party integrations.

Scope of Contribution

My Contributions

  • Led the second-stage robotics integration project.
  • Integrated the robot SDK and API into the factory system.
  • Designed the fleet management architecture.
  • Developed the real-time monitoring dashboard.
  • Implemented robot monitoring and operational analytics.
  • Coordinated integration between robotics and manufacturing systems.
  • Collaborated with team members on automation workflow development.

Team Contributions

  • Additional workflow automation and operational enhancements.

Conclusion

This project represented the transition from robot deployment to full robotics system integration. By utilizing the robot SDK and APIs, the team transformed standalone autonomous robots into a connected fleet that could be monitored, managed, and integrated with factory operations through a custom-built platform.
