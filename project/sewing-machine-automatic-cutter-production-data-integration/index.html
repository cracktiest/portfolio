Overview

Developed machine data acquisition and database integration systems for industrial equipment, enabling production and machine performance data to be collected, stored, and made available for further monitoring and analysis.

Scope

  • Focused on acquiring data directly from industrial machines and integrating the collected data into the database.
  • The system captured machine parameters such as cycle time, running time, idle time, machine alerts, production files, processing timestamps, and inventory transactions.

Machine Screenshots

Implemented Systems

Pattern Seamer

Captured machine cycle time, running time, idle time, and alert logs for monitoring and historical analysis.

Bullmer Automatic Cutter

Acquired processed Gerber file information and processing timestamps to improve traceability and production records.

Needle Manager

Monitored real-time needle stock conditions, including additions and withdrawals with operator and user records.

Result

  • Successfully established a reliable data acquisition layer between industrial machines and the database.
  • Provided structured production and machine data for subsequent backend and frontend applications developed by the software team.
  • Improved visibility into machine performance, operational alerts, and inventory transactions.

Conclusion

This project strengthened my expertise in industrial data acquisition, machine-to-database integration, industrial IoT, and production data management, while enabling manufacturing data to be transformed into structured information for real-time monitoring and operational analysis.
