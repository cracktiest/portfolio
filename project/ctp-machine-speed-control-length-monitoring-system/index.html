Overview

Developed a closed-loop control system for a CTP sweetener machine to automatically regulate motor speed and monitor processed paper length in real time. The system was designed to improve stable operation and provide better insight into machine performance during production.

Challenge

  • The existing machine had no automatic speed regulation.
  • There was no system to monitor processed paper length in real time.
  • Production data was not recorded, making performance evaluation difficult.
  • Stable operation under changing conditions was hard to maintain manually.

Solution

Encoder Feedback

Used rotary encoder feedback to measure motor speed and the processed paper length accurately.

Closed-Loop Control

The controller adjusted motor speed through a Variable Speed Drive (VSD) to maintain stable operation.

Data Logging

Production data was recorded to an SD card for performance analysis and monitoring.

Result

  • Successfully implemented automatic motor speed control.
  • Enabled real-time monitoring of processed paper length.
  • Recorded production data for machine performance analysis.
  • Demonstrated consistent machine performance under different operating conditions.

Conclusion

This project expanded my expertise from basic machine automation to feedback control systems, strengthening my understanding of embedded systems, industrial motor control, and machine monitoring.
