Automatic Elastic Cutting Machine (PID Version)

Redesigned the automatic elastic cutting machine by replacing the previous open-loop motion system with a closed-loop PID control algorithm. The new system utilizes encoder feedback to precisely control material feeding, resulting in higher cutting accuracy and improved positioning stability during continuous production.

Overview

The first-generation version of the elastic cutting machine relied on step calculations to estimate feeding distance. Although it worked for basic automation, mechanical slip, load variation, and accumulated positioning errors reduced accuracy during longer production runs.


This upgraded version replaced the open-loop method with a closed-loop motion control system using encoder feedback and PID control to continuously correct the motor movement before the cutting action is executed.

Challenge

  • Open-loop stepping caused positioning errors during long production runs.
  • Mechanical slip and load variation affected feeding accuracy.
  • Cutting consistency became less reliable under continuous operation.
  • The machine interface needed to be simplified for easier operator use.

Solution

Closed-Loop PID Control

A PID controller continuously adjusts motor movement based on encoder feedback to reach the target feeding length accurately.

Encoder Feedback

Quadrature encoder feedback provides real-time position data for precise motion correction.

Improved Motion Stability

The system reduces positioning error caused by mechanical variation and slip during production.

Infrared Remote Interface

The operator interface was upgraded from keypad input to an infrared remote controller for simpler configuration and operation.

Result

  • Improved feeding accuracy through encoder-based position feedback.
  • Reduced positioning errors caused by mechanical variations and material slip.
  • Achieved smoother and more stable motor movement using PID control.
  • Increased cutting consistency during continuous production.
  • Simplified machine operation with an infrared remote interface.
