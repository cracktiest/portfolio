Overview

This project was developed to replace the manual elastic cutting process in garment manufacturing. The machine automatically feeds elastic material, cuts it to a predefined length, and repeats the process according to the required production quantity.


The system was designed as an embedded automation platform with a keypad interface, LCD display, stepper motor control, and pneumatic actuator-based cutting mechanism.

Challenge

  • The existing process relied on manual cutting, causing inconsistent lengths.
  • Low productivity and high operator workload affected daily output.
  • Production interruptions due to sudden power loss created process instability.

Solution

Embedded Control System

An embedded controller manages the machine sequence, cut length, and production quantity.

Stepper Motor Feeding

The feeding mechanism is driven by a stepper motor to ensure precise elastic movement.

Pneumatic Cutting Actuator

A pneumatic actuator performs the cutting action automatically with repeatable motion.

Keypad & LCD Interface

Operators can configure cutting length and quantity, while progress is shown on an LCD.

EEPROM Recovery

The system restores unfinished production after power interruptions, increasing reliability.

Result

  • Improved cutting consistency and repeatability.
  • Reduced manual intervention and operator workload.
  • Increased overall production reliability with recovery after power loss.
  • Provided valuable hands-on experience in embedded systems and industrial automation design.
