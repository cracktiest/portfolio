Operator Production Monitoring System

Developed an IoT-based production monitoring system to collect real-time operator output and production status in garment manufacturing. The system integrates RFID authentication, wireless remote controls, and Wi-Fi communication to provide live production data, downtime tracking, lost time classification, and operator performance monitoring through a centralized server.

Overview

This project was developed to digitize operator production reporting in garment manufacturing. Previously, production data was recorded manually, making it hard to monitor productivity, identify delays, and analyze downtime across sewing lines.


The solution connects embedded devices, wireless remotes, and a web server to capture real-time production events and provide supervisors with immediate visibility into operator output and line performance.

Challenge

  • Manual production recording caused delayed and inconsistent reporting.
  • Supervisors lacked real-time visibility into operator productivity.
  • Downtime events were difficult to classify and analyze.
  • Production delays and machine status were not visible quickly enough for corrective action.

Solution

RFID Authentication

Operators identify themselves using RFID cards before production begins, ensuring accurate operator tracking and secure login for each shift.

Operator Output Logging

Production output is recorded through a wireless remote during operation, making it easy to add operator output directly to the system.

Downtime Reporting

Dedicated remote buttons allow operators to report lost time reasons such as machine breakdown, personal needs (restroom), supply issues, technical support, and layout changes.

ESP8266 + Wi-Fi Communication

The embedded device communicates with a central web server over Wi-Fi for real-time synchronization.

LCD & RGB LED Feedback

Operators receive immediate visual feedback through an LCD display and RGB LED status indicator.

Result

  • Successfully digitized operator production reporting.
  • Enabled real-time monitoring of operator output and status.
  • Implemented lost time tracking for machine breakdowns, personal needs, supply issues, and other production interruptions.
  • Reduced manual reporting effort and improved data accuracy.
  • Provided supervisors with production visibility and historical records for analysis.
