Overview

Developed an automatic button counting machine to improve the efficiency of counting buttons before the sewing process. The system uses centrifugal force generated by a rotating disc driven by a stepper motor to separate and feed buttons individually, while an infrared sensor detects each button for accurate counting.

Challenge

  • The existing counting process was performed manually, making it time-consuming and prone to human error, especially when handling large production quantities.
  • Button overlap and inconsistent feeding reduced counting accuracy and overall productivity.

Solution

Embedded Automation System

Designed an embedded automation system using an Arduino microcontroller to coordinate button feeding, counting, and machine operation.

Centrifugal Feeding Mechanism

A stepper motor precisely controlled a rotating disc to generate centrifugal force and move buttons individually toward the detection area.

Infrared Counting Logic

An infrared sensor detected every passing button, while the controller continuously counted and displayed production progress.

Result

  • Successfully automated the button counting process.
  • Improved counting accuracy and reduced operator workload.
  • Achieved stable button separation and reliable infrared detection.
  • Delivered a practical low-cost automation solution suitable for garment production.
