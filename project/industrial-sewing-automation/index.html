Overview

This project began as an internal engineering initiative to automate a repetitive sewing process. Instead of purchasing a dedicated automation machine, an existing programmable sewing platform was redesigned and enhanced using pneumatic systems, Arduino-based controllers, mechanical fixtures, and custom control logic.


The resulting workstation successfully automated multiple manual operations while maintaining sewing quality and improving production consistency. The project later became the foundation for several additional automation initiatives within the manufacturing department.

Engineering Challenges

  • Integrating pneumatic actuators with existing industrial equipment.
  • Synchronizing mechanical movements with sewing cycles.
  • Designing reliable interlocks for operator safety.
  • Developing embedded firmware for real-time sequence control.
  • Optimizing timing between sensors, cylinders and servo mechanisms.
  • Reducing implementation cost without sacrificing reliability.

System Architecture

Mechanical Design

Custom brackets, fixtures, pneumatic cylinders, guides and workpiece holders.

Embedded Controller

Arduino firmware controlling valves, sensors, servo motors and sequencing logic.

Pneumatic System

Multiple solenoid valves coordinating workpiece clamping and positioning.

Industrial Machine Integration

Synchronization with the programmable sewing machine through digital I/O signals.

Impact

  • Reduced capital expenditure by approximately 75% compared with dedicated commercial equipment.
  • Improved operator consistency and repeatability.
  • Initiated broader collaboration between Robotics and Production Engineering teams.
  • Inspired multiple follow-up automation projects across manufacturing processes.
  • Contributed to recognition through an internal innovation award in 2024.
